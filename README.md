# 🎨 Styling React

A React project created as part of my learning journey, focused on styling React applications with Tailwind CSS.

The project explores how Tailwind's utility classes can be used directly within React components to create layouts, spacing, colors, typography, states and responsive styling without relying heavily on traditional CSS files.

## ✨ About the Project

Styling React is a small authentication interface created to practice styling and component composition with Tailwind CSS.

The application contains an email and password form with basic validation feedback and styled interactive elements.

## 🧩 Features

- Email and password inputs
- Basic form validation
- Validation feedback for invalid email and password values
- Styled buttons and inputs
- Hover states
- Flexbox-based layouts
- Custom spacing and sizing
- Rounded elements and shadows
- Gradient backgrounds
- Responsive container sizing

## 🎨 Tailwind CSS Concepts Practiced

This project was mainly created to practice Tailwind CSS utility classes, including:

- Width and max-width
- Padding and margins
- Flexbox
- Gaps
- Colors
- Gradients
- Borders and rounded corners
- Shadows
- Typography
- Hover states
- Responsive sizing
- Conditional styling

Example:

```jsx
<div className="w-full max-w-sm p-8 mx-auto rounded shadow-md bg-linear-to-b from-stone-700 to-stone-800">
```
